Matt's Modular Armory is a mod that focuses on giving the player options in how they use tools, weapons and armor by adding modular items which behavior can be changed on the fly.

For more information and download check the mod out on either [Modrinth](https://modrinth.com/mod/matts-modular-armory) or [CurseForge](https://www.curseforge.com/minecraft/mc-mods/matts-modular-armory).
