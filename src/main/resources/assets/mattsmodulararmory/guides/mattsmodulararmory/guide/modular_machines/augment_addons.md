# Augment Addons

## Augment Addons can be inserted into some modular machines

# Silk Touch Augment Addon

Fragile blocks (like glass) mined by a machine with this augment drop themselves

Requires additional 50FE per operation

Only 1 per machine

<Recipe id="silk_touch_augment_addon" />

# Fortune Augment Addon

Increases the amount of items some blocks (like ores) drop

Each level requires additional 250FE per operation

Up to 4 per machine

<Recipe id="fortune_augment_addon" />

# Auto Smelt Augment Addon

Smelts mined blocks

Requires additional 400FE per operation

Only 1 per machine

<Recipe id="auto_smelt_augment_addon" />

# Auto Smelting Fortune Augment Addon

Smelts mined blocks and applies fortune

Each level requires additional 275FE per operation + requires static 450FE

Up to 4 per machine

<Recipe id="auto_smelting_fortune_augment_addon" />

# Void Augment Addon

Voids block drops

Requires additional 10FE per operation

Only 1 per machine

<Recipe id="void_augment_addon" />

# Clay Extractor Augment Addon

Converts mined clay into modular clay and dirt

Higher levels increase the amount of clay

Requires additional 50FE per operation

Up to 4 per machine

<Recipe id="clay_extractor_augment_addon" />
