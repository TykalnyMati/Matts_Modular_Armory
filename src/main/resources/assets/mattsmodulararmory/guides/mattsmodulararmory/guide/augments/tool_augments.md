# Tool Augments

## Tool augments can be inserted only into tools

# Efficiency Augment:
Increases mining speed of tools, high levels can allow for instantly mining blocks

<Recipe id="efficiency_augment" />

# Silk Touch Augment:
Fragile blocks (like glass) mined with this augment drop themselves

Incompatible with Fortune, Auto Smelt and Void

<Recipe id="silk_touch_augment" />

# Fortune Augment:
Increases the amount of items some blocks (like ores) drop

Incompatible with Silk Touch and Void

<Recipe id="fortune_augment" />

# Auto Smelt Augment:
Smelts items dropped from blocks

Each smelting costs 4 extra durability and spawns fire particles

Incompatible with Silk Touch and Void

<Recipe id="auto_smelt_augment" />

# Diamond Sharpened Augment:
Allows the tool to mine blocks that require diamond tools

Useful before obtaining adaptive flesh tier

Increases mining speed equivalently to 1 efficiency augment

<Recipe id="diamond_sharpened_augment" />

# Modular Clay Extractor Augment:
Right-clicking with the tool on clay turns it into dirt and drops pieces of modular clay

Consumes 5 durability per use

The amount dropped changes with level with this formula: 2 + \<2, level) items

Incompatible with other right-clicking augments

<Recipe id="modular_clay_extractor_augment" />

# Scaffolding Augment:
Right-clicking with the tool creates a temporary scaffolding block

Consumes 2 durability per use

The block starts breaking when no entity is on top of it for a set amount of time

The amount of time to break changes with level, on the first level it's 2 seconds, every level adds a bonus second to the breaking time

Incompatible with other right-clicking augments

<Recipe id="scaffolding_augment" />

# Illuminator Augment:
Right-clicking with the tool creates a slightly visible light

Consumes 5 durability per use

Incompatible with other right-clicking augments

<Recipe id="illuminator_augment" />

# Fire Starter Augment:
Right-clicking with the tool creates fire

Consumes 2 durability per use

Incompatible with other right-clicking augments

<Recipe id="fire_starter_augment" />

# Overclock Augment:
Grants Haste when used

- Level I: Haste I | 40 seconds
- Level II: Haste II | 30 seconds
- Level III: Haste III | 20 seconds

Uses Level * 10 durability with 60-second cooldown

<Recipe id="overclock_augment" />

# Void Augment:
Voids drops of broken blocks

Incompatible with Silk Touch, Fortune and Auto Smelt

<Recipe id="void_augment" />
